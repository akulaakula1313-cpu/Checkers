 v2.3.1

Премиальные шашки SANI GROUP по кастомной схеме SANI:

- 8×8, игра только по тёмным клеткам.
- Начальная расстановка: по 12 шашек у каждого игрока, первые три ряда с каждой стороны (по 4 шашки в каждом ряду).
- Простая шашка ходит по диагонали вперёд на 1 поле.
- Простая шашка берёт и вперёд, и назад.
- Взятие обязательно: если есть хотя бы одно взятие, обычный ход запрещён.
- Дамка ходит по диагонали на любое число свободных клеток.
- Дамка берёт фигуру соперника на расстоянии и может выбрать любое свободное поле после неё.
- После взятия при наличии продолжения игрок может продолжить серию или добровольно нажать «ЗАКОНЧИТЬ СЕРИЮ».
- При нескольких вариантах продолжения разрешён любой вариант.
- При достижении последней линии шашка становится дамкой.

## Режимы

- Два игрока на одном устройстве.
- Бот: 3 уровня, ход и расчёт результата на сервере.
- Онлайн 1×1: комнаты по 4 цифрам, сервер проверяет каждый ход, ставки и выплаты.
- Предложение/принятие/отказ от ничьей, сдача, reconnect и grace period при временном отключении.
- Чат в онлайн-партии.
- VIP-подсказка.
- Магазин досок и наборов шашек.
- Профиль, рейтинг, лидерборд и админ-панель.
- Адаптивный интерфейс PC/mobile.

## Запуск

```bash
npm install
ADMIN_PASSWORD='change-me' npm start
```

Для Render задайте `ADMIN_PASSWORD`. Файловая база использует `DATA_DIR`; для сохранения данных после рестартов/деплоев Render нужен Persistent Disk, например `/var/data`, или внешняя БД.

## v2.2 — сила ботов
- **1 — Безразрядник:** интуитивный новичок, допустимые ходы с базовым приоритетом взятий и намеренной вариативностью.
- **2 — 1-й разряд:** тактический альфа-бета поиск, продвижение, активность и приоритет взятий.
- **3 — Гроссмейстер:** более глубокий позиционно-тактический поиск с таблицей транспозиций, оценкой материала, центра, темпа и дамок.
- Бот умеет принимать решение **продолжить серию или закончить её**, как требует схема SANI CHECKERS.
- Проведена серия автоматических партий между уровнями для калибровки силы.

Бот-матчи поддерживают ставки в виртуальных фишках; сервер является источником истины по списанию и выплатам. Реальные деньги не используются.

## v2.5.0 — Match UX and account persistence
- Быстрый выбор ставок и предпросмотр банка.
- Экран результата с победителем/проигравшим, причиной и банком.
- Реванш с подтверждением обоих игроков и автоматическим созданием новой партии.

- Дополнительный lifecycle QA охватывает ставки, сдачу, реванш, reconnect, disconnect payout и rename persistence.
